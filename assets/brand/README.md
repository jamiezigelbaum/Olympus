# Olympus brand assets

| Asset | Size | Use |
| --- | --- | --- |
| [Banner](banner.png) | 2157 × 729 PNG | Approved panoramic mountain artwork, also used in the repository README. |
| [Square mountain](mountain-square.png) | 1254 × 1254 PNG | Approved detailed mountain portrait with the gold-lit face, snowy summit, and Olympus palace. |
| [Mountain emoji](mountain-emoji.png) | 512 × 512 RGBA PNG | Transparent mountain emoji, an earlier plugin icon. |

The banner and square mountain are the approved generated artwork. The plugin
icon is the crowned mountain: `assets/icon.png` (what OpenClaw and ClawHub show)
is a copy of `assets/app-icon.png` (the desktop app and ChatGPT listing icon),
and `test/plugin-icon.test.ts` keeps them identical. The runtime assets remain at
`assets/olympus-banner.png`, `assets/icon.png` and `assets/app-icon.png`; this
folder collects the brand artwork for reuse.
