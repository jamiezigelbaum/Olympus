# Security

Please report security problems privately, never in a public issue:
[open a private report](https://github.com/jamiezigelbaum/Olympus/security/advisories/new)
on GitHub. Include what you found, how to reproduce it, and the Olympus
version (`olympus --version`).

Olympus is a free, open-source project maintained in the open. Reports are
read and fixed as time allows; there is no bug bounty.
