Run Olympus on an always-on Mac

Most people run Olympus on the Mac they use every day, and nothing here applies to them. This page is for a Mac that stays on as a small server, such as a Mac mini or Mac Studio in a cupboard, reached over Screen Sharing. Decide the points below before you install; changing them later takes longer.

1. Choose the accounts

  • An administrator account for you, used only to change settings.
  • A standard account for Olympus. Olympus and all of its data live here.
  • A separate account for any AI agent on the same Mac, such as OpenClaw or Hermes. The agent must not be able to read the Olympus account's home folder, so it only ever sees what Olympus chooses to answer. Never install Olympus inside the agent's own account.

Create the accounts in System Settings, Users & Groups. Accounts made there can unlock FileVault. Accounts made with command-line tools may not, and fixing that needs extra steps.

2. Keep Olympus running when no one is logged in

Install Olympus while logged in to the Olympus account. When the dashboard asks how this computer will run, choose Always on, as a server, or later turn on Keep Olympus running when no one is logged in in the dashboard. Your Mac asks for an administrator's name and password once. After that Olympus starts by itself after a restart, without anyone logging in.

3. Decide about FileVault

FileVault keeps your data encrypted if the Mac is stolen, and we recommend it. The trade-off: after every restart, the disk stays locked until someone unlocks it. Olympus starts as soon as it is unlocked.

  • Unlock in person at the Mac, or remotely, which recent versions of macOS allow over SSH.
  • Remote unlock is much more reliable on a wired network than on Wi-Fi. Test a restart and a remote unlock before you rely on it.
  • Plan for power cuts: after one, the Mac waits at the unlock screen until someone unlocks it.

4. Set up the network

  • Use Ethernet if you can.
  • Give the Mac a fixed address on your network. Most routers call this a DHCP reservation.
  • If you use Tailscale, use the version that runs as a system service rather than the menu-bar app, which stops when you log out. Check that the Mac still shows as connected in Tailscale after a restart, before anyone logs in.
  • Turn on Screen Sharing in System Settings, General, Sharing. If it does not answer after turning it on, switch it off and on again there.

5. Connect agents

On the dashboard's Agents page, choose Agent on another account of this computer for an agent on the same Mac, or Agent on my tailnet for one on another of your machines. Each agent gets its own key, which you can revoke there at any time. Neither choice opens Olympus to your local network or the internet.

6. Know which Mac you are on

The top of the Olympus dashboard shows the computer's name and the account Olympus runs as. When you or an assistant helping you switch between machines, check it before changing anything.

If something goes wrong

Open the dashboard and press Copy details on the card that failed, or Copy system report on the Help page, and send it to support. The report contains no names, messages or file paths. You never need to run commands in Terminal for support. If an assistant is helping you, ask it not to send you long commands to paste.
