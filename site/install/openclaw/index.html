Install with OpenClaw

On Linux, on a server, or on a Mac that already runs OpenClaw, Olympus installs as an OpenClaw plugin. Your OpenClaw agents use it natively: nothing to paste, no connector to add.

Before you start

  • OpenClaw 2026.7.1 or later, on macOS or Linux. On Linux, Olympus is tested on Omarchy (Arch Linux) and Ubuntu 24.04 LTS, on x86_64.
  • A Node version your OpenClaw supports, and Bun 1.2 or later.

On Linux

On Omarchy or Ubuntu 24.04 LTS you can also install Olympus with one line, without OpenClaw. With OpenClaw on Linux, install these first so that Olympus can read scans and pictures of text, search photos by what is in them and transcribe voice notes (on Omarchy):

sudo pacman -S --needed tesseract tesseract-data-eng poppler libvips libheif ffmpeg

Anonymous answers work on a Mac and on supported Linux x64 computers once Olympus's network isolation checks pass. Apple Messages is Mac only.

Install

The easy way is to ask an agent. Paste this into OpenClaw, or any agent that can use a terminal:

Install Olympus by reading https://raw.githubusercontent.com/jamiezigelbaum/Olympus/main/INSTALL_FOR_AGENTS.md and following it step by step. Walk me through setup and ask me about my data and privacy preferences.

It checks the release, installs the plugin, and walks you through your sources and your privacy choices. To do it by hand instead, follow the Quickstart.

Open the dashboard

  • In OpenClaw's Control UI (2026.9.2 or later): turn on Settings, Labs, Custom plugin UI, and Olympus appears in the sidebar.
  • From the command line: run olympus dashboard. The link works once, for 15 minutes.
  • On a server: run olympus dashboard --no-open there, and open the link through an SSH tunnel on the same port: ssh -N -L PORT:127.0.0.1:PORT you@your-server.

Good to know

  • To keep one OpenClaw agent away from Olympus, add the Olympus tools to that agent's deny list in agents.list[].tools.
  • Remote access, which lets apps in the cloud reach Olympus, is off under OpenClaw until you turn it on from the dashboard's Agents page.
  • To remove it: olympus worker uninstall keeps your data; olympus data delete --all removes it.
