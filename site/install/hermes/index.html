Connect Hermes

Hermes Agent runs Olympus as a local MCP server and sees four tools: ask, collect a long answer, check which sources are ready, and ask anonymously.

Before you start

  • Olympus installed on your computer. On a Mac, that is one line in Terminal; on Linux or a server, install with OpenClaw.

Connect

  1. Add the server. Use the absolute path to the olympus command: 
    hermes mcp add olympus --command /absolute/path/to/olympus --args serve
hermes mcp test olympus
  2. Limit it to four tools. Make the olympus entry in ~/.hermes/config.yaml match: 
    mcp_servers:
  olympus:
    command: /absolute/path/to/olympus
    args: [serve]
    tools:
      include: [source_answer, source_answer_result, source_index_status, ask_anonymously]
      prompts: false
      resources: false
  3. Reload. Restart Hermes or run /reload-mcp. The tools appear as mcp_olympus_source_answer, mcp_olympus_source_answer_result, mcp_olympus_source_index_status and mcp_olympus_ask_anonymously.
  4. Add the skill (optional). Copy the ask-sources folder to ~/.hermes/skills/ask-sources/, so Hermes knows when to ask.

On a Mac you installed with the one line, the command is ~/.local/bin/olympus. Under OpenClaw, it is bin/olympus inside the plugin folder: run openclaw plugins inspect olympus --json and use plugin.rootDir.
