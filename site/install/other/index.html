Connect any MCP app

Any app on your computer that speaks MCP can ask Olympus. It runs Olympus as a local server, over standard input and output.

Before you start

  • Olympus installed on your computer. On a Mac, that is one line in Terminal; on Linux or a server, install with OpenClaw.

Connect

Add a server named olympus whose command is the absolute path to olympus, with the argument serve. In apps that take a JSON config, that looks like:

{
  "mcpServers": {
    "olympus": {
      "command": "/Users/you/.local/bin/olympus",
      "args": ["serve"]
    }
  }
}

On a Mac you installed with the one line, the command is ~/.local/bin/olympus. Under OpenClaw, it is bin/olympus inside the plugin folder: run openclaw plugins inspect olympus --json and use plugin.rootDir.

Tell it when to ask Olympus

Paste this into wherever the app keeps its instructions. Then it asks Olympus on its own whenever your own records might hold the answer.

Olympus is my private search over my own email, files, messages, notes, bookmarks and saved reading. You can ask it through its source_answer tool.

Ask Olympus whenever my question might be answered from my own records: what someone told me, what a document or contract says, or when something happened. If you are not sure, ask it anyway. You do not need me to mention Olympus.

Ask one question at a time, in plain words, and wait for each answer before asking the next. Answers can take a few minutes. If Olympus says it is still working and gives you a job_id, call source_answer_result with that job_id, again while it says working, and pass on the answer it returns. Do not ask the same question again.

Pass on what Olympus answers with its citations, and say plainly what it could not find. Do not guess past it or fill gaps from memory.

Use source_index_status only to check which of my sources are ready.

Good to know

  • Long answers are handed off: the app gets a job id and collects the answer with source_answer_result. The instructions above tell it how.
  • Apps that run in the cloud reach Olympus through the Olympus relay. Today that is ChatGPT; Claude and Grok are coming.
