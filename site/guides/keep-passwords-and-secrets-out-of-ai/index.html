How do I keep passwords and secrets out of AI chats?

Never paste them, and make sure any tool that reads your files on your behalf filters secrets out before anything reaches the AI. Most leaks are accidental: a pasted config file, a screenshot, or an email with a recovery code that a connector passes along.

Where secrets slip in

  • Pasting logs, config files or code that contain API keys.
  • Connectors that read your whole inbox or drive, including password-reset emails and saved credentials.
  • Screenshots and PDFs with account numbers or codes in them.

What helps

  1. Keep passwords in a password manager, not in notes or email.
  2. Run a secret scanner (for example gitleaks) on code before you share it.
  3. Rotate any key you have pasted into a chat.
  4. Use tools that check content on your computer before sending it.

How Olympus handles secrets

Olympus looks for common forms of secrets, such as private keys, API keys and labeled passwords, in the items it indexes on your computer. Once it recognizes a Secret, it never sends it anywhere or answers from it, and removes its contents from the search index. Recognition can miss unusual forms, and an item it misses is labeled like any other item, so these habits still matter. Details are in the privacy policy.
